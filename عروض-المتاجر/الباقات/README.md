# باقات المتاجر الإلكترونية — وصل تك

هذه الباقات مقسمة اعتمادًا على ملفات المميزات المعتمدة في الفرع نفسه:

- [المميزات العامة المعتمدة](../المميزات-العامة.md)
- [المميزات التفصيلية المعتمدة](../المميزات-التفصيلية.md)

## العروض

| الباقة | طريقة استقبال الطلب | مستوى الإدارة |
|---|---|---|
| [الأولى — متجر واتساب](./01-متجر-واتساب/المميزات-العامة.md) | ينتقل العميل إلى واتساب لإرسال طلبه | إدارة كتالوج المنتجات |
| [الثانية — متجر إلكتروني](./02-متجر-إلكتروني/المميزات-العامة.md) | الطلب والسلة داخل الموقع | المنتجات والمخزون والطلبات والعملاء |
| [الثالثة — متجر متكامل](./03-متجر-متكامل/المميزات-العامة.md) | الطلب والسلة داخل الموقع | إدارة متكاملة مع المحتوى والتسويق والتحسين والتحليل |

كل باقة لها ملف عام وملف تفصيلي. الباقة الثانية تشمل خصائص التصفح والكتالوج من الأولى ولكن تستبدل مسار واتساب بطلب داخلي؛ ويظل واتساب وسيلة تواصل. الباقة الثالثة تشمل الثانية مع المميزات الإضافية.
