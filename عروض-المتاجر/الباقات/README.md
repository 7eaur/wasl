## الباقات

1. [الباقة الأولى — متجر العرض والطلب عبر واتساب](./01-متجر-واتساب.md): كتالوج للمنتجات مع إرسال تفاصيل الطلب إلى واتساب، دون إنشاء طلب داخل الموقع.
2. [الباقة الثانية — المتجر الإلكتروني الأساسي](./02-متجر-إلكتروني.md): سلة وطلبات داخل الموقع مع إدارة المنتجات والمخزون والعملاء والفواتير.
3. [الباقة الثالثة — المتجر المتكامل والنمو](./03-متجر-متكامل.md): جميع مزايا الباقة الثانية مع إدارة المحتوى والتسويق وSEO والتحليلات وخدمة العملاء.
