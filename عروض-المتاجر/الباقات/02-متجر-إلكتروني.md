# الباقة الثانية — المتجر الإلكتروني الأساسي

## أولًا: المميزات العامة

متجر يستقبل الطلبات داخل الموقع ويمنح الإدارة لوحة تشغيل للمنتجات والمخزون والعملاء والطلبات والفواتير، مع الدفع عند الاستلام والتحويل البنكي.

**مناسب لـ:** المتاجر التي تريد تنظيم المبيعات إلكترونيًا بدل استلام كل الطلبات بالمحادثات.

> تتضمن جميع مميزات الباقة الأولى — متجر العرض والطلب عبر واتساب، بالإضافة إلى ما يرد هنا.

### 1. واجهة المتجر

- جميع مميزات العرض والتصفح من الباقة الأولى.
- سلة تسوق كاملة وإتمام الطلب عبر الموقع.
- شراء كزائر أو بحساب عميل.
- المفضلة ومقارنة المنتجات وتقييمات العملاء.
- كوبونات خصم وعرض المنتجات المخفضة.

### 2. الطلبات والمدفوعات

- استقبال الطلبات وتحديث حالاتها من لوحة الإدارة.
- الدفع عند الاستلام أو بالتحويل البنكي.
- عرض حالات الدفع وإصدار الفواتير.
- حساب الأسعار والخصومات والضرائب ورسوم الشحن.
- إدارة الإلغاء والاسترجاع والاسترداد.

### 3. المنتجات والمخزون

- إدارة المنتجات والأقسام والعلامات التجارية ومتغيرات اللون والمقاس.
- تتبع كمية المخزون وتحديثها حسب الطلبات.
- تنبيهات انخفاض المخزون والمنتجات النافدة.
- استيراد وتصدير بيانات المنتجات.

### 4. العملاء والشحن

- حسابات العملاء وعناوينهم وسجل الطلبات.
- إعداد مناطق التوصيل وطرق الشحن والاستلام.
- تأكيد الطلبات وإشعارات حالاتها بالبريد الإلكتروني.

### 5. الإدارة والتقارير

- لوحة تحكم للمنتجات والطلبات والعملاء.
- إحصائيات الطلبات والمبيعات والمنتجات الأكثر مبيعًا.
- إعدادات العملات والضرائب والبريد والإشعارات.
- صلاحيات المستخدمين والنسخ الاحتياطي.

## ثانيًا: المميزات التفصيلية

متجر يستقبل الطلبات داخل الموقع ويمنح الإدارة لوحة تشغيل للمنتجات والمخزون والعملاء والطلبات والفواتير، مع الدفع عند الاستلام والتحويل البنكي.

**مناسب لـ:** المتاجر التي تريد تنظيم المبيعات إلكترونيًا بدل استلام كل الطلبات بالمحادثات.

> تتضمن جميع مميزات الباقة الأولى — متجر العرض والطلب عبر واتساب، بالإضافة إلى ما يرد هنا.

### 1. واجهة الشراء

- كل مميزات الكتالوج والتصفح في الباقة الأولى ضمن متجر إلكتروني كامل.
- سلة تسوق لإضافة المنتجات وتعديل كمياتها وحذفها.
- عرض إجمالي المنتجات والخصومات والضرائب والتوصيل قبل التأكيد.
- إتمام الطلب مع الاسم والهاتف والعنوان وطريقة الدفع والتوصيل.
- الشراء كزائر وإنشاء حساب عميل لتتبع الطلبات.
- قوائم مفضلة ومقارنة المنتجات وتقييماتها.

### 2. استقبال الطلبات وإدارتها

- توليد رقم مستقل لكل طلب مع بيانات العميل والعنوان والمنتجات.
- عرض الطلبات الجديدة والبحث عنها وتصفيتها حسب الحالة والتاريخ.
- تحديث حالة الطلب من جديد إلى مؤكد ثم قيد التجهيز والشحن والمكتمل أو الملغي.
- إصدار وطباعة فواتير الطلبات.
- متابعة طلبات الإلغاء والاسترجاع والاسترداد.
- تصدير بيانات الطلبات.

### 3. الدفع والشحن

- توفير الدفع عند الاستلام والتحويل البنكي.
- تسجيل حالة الدفع وتأكيد المدفوعات اليدوية.
- عرض تفاصيل المعاملات والفواتير والضرائب.
- إعداد مدن ومناطق التوصيل وطرق الشحن أو الاستلام من المتجر.
- تحديث حالة الشحن وإبلاغ العميل عبر البريد الإلكتروني.

### 4. المنتجات والمخزون

- إضافة المنتجات وأوصافها وصورها ومواصفاتها وألوانها ومقاساتها.
- تحديد سعر ومخزون كل متغير.
- ضبط الكمية المتوفرة وتحديثها عند تنفيذ الطلب.
- منع شراء المنتج النافد وتنبيه الإدارة إلى انخفاض المخزون.
- استيراد وتصدير بيانات المنتجات.

### 5. العملاء والإدارة

- تسجيل حساب للعميل وحفظ العناوين وتاريخ المشتريات.
- إدارة حسابات العملاء ومتابعة الطلبات من لوحة التحكم.
- إدارة الكوبونات والتخفيضات على المنتجات.
- لوحة للطلبات والمبيعات والمنتجات والمخزون.
- إعدادات الحسابات والصلاحيات والضرائب والإشعارات.
- نسخ احتياطي للبيانات وإجراءات الاستعادة.

### 6. حدود الباقة

- الطلبات تُؤكَّد وتُدار داخل الموقع، بعكس متجر واتساب.
- بوابات الدفع الإلكتروني المباشرة وربط شركات الشحن الخارجية وتطبيق الهاتف إضافات مستقلة.
- أدوات SEO المتقدمة وإدارة المقالات والمحادثة المباشرة والتحليلات التسويقية ضمن الباقة الثالثة.
