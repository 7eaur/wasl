# الباقة الثانية — المتجر الإلكتروني الأساسي

## أولًا: المميزات العامة

### 1. واجهة المتجر وتجربة التسوق
- تصميم احترافي ومتجاوب مع جميع الأجهزة.
- دعم اللغة العربية واتجاه RTL وواجهة سهلة الاستخدام.
- عرض المنتجات ضمن أقسام وتصنيفات منظمة.
- بحث سريع وفلاتر وخيارات لترتيب المنتجات.
- صفحات منتجات بالصور والمواصفات وخيارات الألوان والمقاسات.
- المفضلة ومقارنة المنتجات وتقييمات العملاء.
- عرض المنتجات المرتبطة والعروض والتخفيضات.
- مشاركة المنتجات والتواصل عبر واتساب ووسائل التواصل.
- دعم تعدد العملات وفق إعدادات المتجر.

### 2. إدارة المنتجات والأقسام
- إضافة المنتجات وتعديلها وإدارتها من لوحة التحكم.
- إدارة الأقسام الرئيسية والفرعية والعلامات التجارية.
- إدارة الصور والأوصاف والمواصفات والخيارات.
- تحديد الأسعار والتخفيضات لكل منتج.
- إدارة المنتجات متعددة الألوان والمقاسات.
- التحكم في توفر المنتجات وظهورها.
- استيراد وتصدير بيانات المنتجات.

### 3. إدارة المخزون
- متابعة كميات المنتجات والمخزون.
- تحديث الكميات تلقائيًا حسب الطلبات.
- تنبيهات انخفاض المخزون والمنتجات النافدة.
- تحديد الكميات المتاحة لكل منتج وخيار.

### 4. سلة التسوق وإتمام الطلب
- سلة تسوق متكاملة مع تعديل الكميات والمنتجات.
- احتساب الأسعار والخصومات ورسوم التوصيل.
- إتمام الطلب بخطوات واضحة ومبسطة.
- إمكانية الشراء دون إنشاء حساب.
- اختيار عنوان التوصيل وطريقة الدفع والشحن.
- تأكيد الطلب وإصدار رقم مرجعي للمتابعة.

### 5. إدارة الطلبات والمبيعات
- استقبال الطلبات وإدارتها من لوحة مركزية.
- متابعة الطلبات وتحديث حالاتها.
- عرض تفاصيل العملاء والمنتجات المطلوبة.
- إدارة الإلغاء والاسترجاع والاسترداد.
- إصدار الفواتير وطباعتها.
- البحث والتصفية وتصدير بيانات الطلبات.
- متابعة إجمالي الطلبات والمبيعات.

### 6. المدفوعات والفواتير
- دعم الدفع عند الاستلام والتحويل البنكي.
- إدارة حالات الدفع والمعاملات.
- إصدار الفواتير وتحميلها أو طباعتها.
- إعداد الضرائب ورسوم الخدمات.
- تقارير المدفوعات والتحصيل.

### 7. الشحن والتوصيل
- إعداد مناطق ومدن التوصيل.
- توفير خيارات الشحن والاستلام.
- متابعة حالة تجهيز وشحن الطلب.
- إدارة معلومات التوصيل الخاصة بالعملاء.

### 8. إدارة العملاء والحسابات
- إنشاء حسابات العملاء وتسجيل الدخول.
- إدارة البيانات الشخصية وعناوين التوصيل.
- متابعة الطلبات وسجل المشتريات.
- حفظ المنتجات المفضلة.
- إدارة حسابات العملاء من لوحة التحكم.
- متابعة مشتريات العملاء وتفاعلهم.

### 9. التسويق الأساسي
- إنشاء الكوبونات والتخفيضات.
- تحديد شروط الخصومات وفترات صلاحيتها.
- إدارة البنرات الإعلانية.
- عرض المنتجات المميزة والأكثر مبيعًا.

### 10. صفحات المتجر
- عرض الصفحة الرئيسية والبنرات والأقسام.
- صفحة من نحن وصفحة تواصل معنا.
- صفحات سياسة الشحن والاستبدال والخصوصية والشروط.
- نموذج الاستفسارات وروابط التواصل.

### 11. لوحة الإدارة والموظفين
- لوحة تحكم مركزية لإدارة المتجر.
- إدارة المنتجات والطلبات والعملاء والمخزون.
- إدارة الأسعار والمدفوعات والشحن.
- إضافة الموظفين وتحديد صلاحياتهم.
- إدارة إعدادات العملات والضرائب والإشعارات.

### 12. التقارير الأساسية
- تقارير المبيعات والإيرادات.
- إحصائيات الطلبات وحالاتها.
- تقارير المنتجات الأكثر مبيعًا.
- إحصائيات العملاء والمشتريات.
- تقارير المخزون والمدفوعات والمرتجعات.

### 13. الإشعارات والتواصل
- رسائل تأكيد الطلبات.
- إشعارات تحديث حالات الطلب والدفع والشحن.
- تنبيهات الإدارة عند استقبال الطلبات.
- إشعارات عبر البريد الإلكتروني.
- نموذج للتواصل والاستفسارات ورابط واتساب.

### 14. الحماية والأمان والأداء
- اتصال آمن باستخدام HTTPS وشهادة SSL.
- حماية حسابات العملاء والإدارة.
- إدارة صلاحيات الوصول.
- حماية بيانات العملاء والمعاملات.
- إعداد النسخ الاحتياطي والاستعادة.
- تحسين سرعة التصفح وتحميل الصور.
- تحسين الأداء والتوافق مع الأجهزة والمتصفحات.

## ثانيًا: المميزات التفصيلية

### 1. واجهة المتجر وتجربة التسوق

#### التصميم والواجهة

- تصميم احترافي يعكس هوية المتجر التجارية.
- توافق مع الكمبيوتر والهواتف والأجهزة اللوحية.
- دعم العربية واتجاه العرض RTL.
- قوائم تنقل واضحة وسهلة الاستخدام.
- إمكانية عرض الأسعار بعملات مختلفة حسب إعدادات النظام.
- واجهة منظمة لعرض الأقسام والمنتجات والعروض.

#### البحث وتصفح المنتجات

- البحث السريع باستخدام اسم المنتج أو الكلمات المرتبطة به.
- تصفية المنتجات حسب السعر والقسم والعلامة التجارية والمواصفات.
- ترتيب المنتجات حسب السعر والأحدث والأكثر مبيعًا.
- عرض المنتجات ضمن أقسام رئيسية وفرعية.
- سهولة الانتقال بين الأقسام وصفحات المنتجات.

#### صفحات المنتجات

- صفحة مستقلة لكل منتج.
- معرض صور لعرض المنتج من زوايا مختلفة.
- عرض صور متعددة وفيديو للمنتج.
- إظهار الاسم والسعر والوصف والمواصفات.
- اختيار اللون أو المقاس أو الحجم قبل الشراء.
- إظهار حالة توفر المنتج.
- عرض المنتجات المرتبطة والمقترحة.
- عرض تقييمات العملاء وآرائهم.

#### التفاعل والتسوق

- إضافة المنتجات إلى سلة التسوق.
- إضافة المنتجات إلى المفضلة.
- مقارنة المنتجات.
- مشاركة روابط المنتجات عبر واتساب ووسائل التواصل.
- إمكانية إضافة زر واتساب للاستفسار.
- عرض التخفيضات والعروض بصورة واضحة.
- صفحات خاصة بالعروض والمجموعات الموسمية.
- عرض المنتجات الجديدة والمميزة والأكثر مبيعًا.



### 2. إدارة المنتجات والأقسام

#### إدارة بيانات المنتجات

- إضافة منتجات جديدة وتعديلها وحذفها أو تعطيل عرضها.
- تنظيم المنتجات في أقسام رئيسية وفرعية.
- إضافة وإدارة العلامات التجارية.
- التحكم في ترتيب ظهور المنتجات داخل الأقسام.

#### محتوى المنتج

- إضافة صور متعددة لكل منتج.
- إضافة فيديو توضيحي للمنتج.
- كتابة وصف مختصر ووصف تفصيلي.
- إضافة المواصفات والخصائص الفنية.
- تحديد السعر الأساسي وسعر التخفيض.
- إدارة الأسعار الخاصة بالعروض.
- تحديد المنتجات المرتبطة والمكملة.

#### خيارات المنتجات

- إضافة منتجات بألوان ومقاسات وأحجام مختلفة.
- تحديد سعر مستقل لكل خيار عند الحاجة.
- تحديد كمية المخزون لكل متغير.
- تخصيص صور للخيارات المختلفة للمنتج.

#### الإدارة الجماعية

- استيراد بيانات المنتجات باستخدام Excel أو CSV.
- تصدير بيانات المنتجات.
- التحكم في حالة عرض المنتجات المتوفرة وغير المتوفرة.



### 3. إدارة المخزون

#### متابعة الكميات

- معرفة الكمية المتوفرة لكل منتج.
- تحديث المخزون تلقائيًا وفق دورة تنفيذ الطلب.
- متابعة الكميات حسب اللون أو المقاس.
- منع شراء المنتجات النافدة وفق الإعدادات.
- عرض حالة المنتج عند نفاد الكمية.
- تحديد الحد الأدنى للمخزون.

#### تنبيهات المخزون

- تنبيهات للمنتجات منخفضة المخزون.
- معرفة المنتجات النافدة.
- تحديد المنتجات التي تحتاج إعادة توفير.



### 4. سلة التسوق وإتمام الطلب

#### سلة التسوق

- إضافة منتج أو أكثر إلى سلة التسوق.
- تعديل كميات المنتجات وحذف المنتجات من السلة.
- عرض تفاصيل السلة والأسعار.
- حساب إجمالي قيمة المنتجات.
- احتساب الخصومات والكوبونات.
- احتساب الضرائب ورسوم الشحن حسب الإعدادات.
- الاحتفاظ بالسلة لاستكمال الشراء لاحقًا.

#### إتمام الشراء

- إتمام الطلب من خلال خطوات واضحة.
- إمكانية الشراء كزائر.
- إدخال اسم العميل وبيانات التواصل.
- إضافة عنوان التوصيل.
- اختيار طريقة التوصيل وطريقة الدفع.
- مراجعة المنتجات والإجمالي النهائي قبل التأكيد.
- إنشاء رقم مرجعي مستقل لكل طلب.
- عرض رسالة تؤكد تسجيل الطلب.

#### خدمات إضافية للعميل

- حفظ عنوان أو أكثر للعميل المسجل.
- متابعة الطلب بعد الشراء.
- عرض الطلبات السابقة.



### 5. إدارة الطلبات والمبيعات

#### استقبال الطلبات

- استقبال طلبات العملاء من المتجر الإلكتروني.
- عرض الطلبات الجديدة في لوحة التحكم.
- إنشاء سجل مستقل لكل طلب.
- عرض رقم الطلب وتاريخه وقيمته.
- عرض بيانات العميل وعنوان التوصيل.
- عرض المنتجات والكميات والأسعار المطلوبة.

#### معالجة الطلبات

- تحديث حالات الطلب بحسب دورة العمل.
- حالات مثل: جديد، قيد المراجعة، مؤكد، قيد التجهيز، تم الشحن، مكتمل، ملغي.
- تعديل بيانات الطلب وفق صلاحيات المستخدم.
- متابعة حالة الدفع المرتبطة بالطلب.
- تسجيل حالة التجهيز والشحن.
- إرسال تحديثات حالة الطلب إلى العميل.

#### الإلغاء والاسترجاع

- إلغاء الطلبات وفق سياسة المتجر.
- متابعة الطلبات الملغاة.
- إدارة طلبات الاسترجاع.
- تسجيل المبالغ المستردة.
- تحديث حالة طلب الاسترداد.

#### إدارة الطلبات والتقارير

- البحث باستخدام رقم الطلب أو بيانات العميل.
- تصفية الطلبات حسب التاريخ والحالة.
- عرض الطلبات المكتملة وغير المكتملة.
- إصدار وطباعة الفواتير.
- طباعة تفاصيل الطلب للمستودع.
- تصدير بيانات الطلبات.
- متابعة إجمالي المبيعات والطلبات.



### 6. المدفوعات والفواتير

#### وسائل الدفع

- الدفع عند الاستلام.
- الدفع عن طريق التحويل البنكي.
- إرفاق إثبات التحويل البنكي.
- اختيار وسائل الدفع في صفحة إتمام الطلب.
- دعم أكثر من عملة وفق إعدادات المتجر.

#### إدارة المدفوعات

- متابعة حالة الدفع لكل طلب.
- حالات الدفع: مدفوع، غير مدفوع، بانتظار التحقق، مسترد.
- عرض تفاصيل المعاملات المالية.
- تأكيد المدفوعات اليدوية من لوحة التحكم.
- متابعة الطلبات غير المدفوعة.
- إدارة طلبات استرداد الأموال وفق وسيلة الدفع.

#### الفواتير والضرائب

- إنشاء فواتير للطلبات.
- عرض الفواتير وتحميلها أو طباعتها.
- تحميل الفواتير بصيغة PDF.
- إعداد الضرائب ورسوم الخدمات.
- عرض قيم الضرائب والشحن والخصومات في الفاتورة.
- تقارير المدفوعات والمبالغ المحصلة.



### 7. الشحن والتوصيل

#### إعدادات التوصيل

- إضافة مناطق ومدن التوصيل.
- إمكانية تقديم الشحن المجاني بشروط محددة.
- تحديد طرق الشحن للعملاء.
- دعم خيار الاستلام المباشر من المتجر.

#### إدارة الشحن

- عرض عنوان العميل وتفاصيل التوصيل.
- تحديث حالة تجهيز الطلب وشحنه.
- تسجيل بيانات الشحنة ورقم التتبع.
- إبلاغ العميل عند تحديث حالة الشحن.



### 8. إدارة العملاء والحسابات

#### حساب العميل

- إنشاء حساب جديد.
- تسجيل الدخول باستخدام البريد الإلكتروني وكلمة المرور.
- تسجيل الدخول بواسطة Google.
- تحديث بيانات الملف الشخصي.
- إضافة عناوين توصيل متعددة.
- عرض سجل المشتريات.
- متابعة حالات الطلبات.
- حفظ قائمة المنتجات المفضلة.

#### إدارة العملاء

- عرض حسابات العملاء من لوحة التحكم.
- البحث عن العملاء باستخدام بياناتهم.
- تعديل بيانات العميل.
- معرفة سجل طلبات العميل.
- متابعة إجمالي مشتريات العميل.
- تفعيل أو تعطيل حسابات العملاء.



### 9. التسويق الأساسي

#### الكوبونات والتخفيضات
- إنشاء كوبونات خصم.
- تحديد خصم بنسبة مئوية أو مبلغ ثابت.
- تحديد مدة صلاحية الكوبون.
- تحديد عدد مرات استخدامه.
- تخصيص الكوبونات لمنتجات أو أقسام معينة.
- تخفيض أسعار منتجات محددة.
- إدارة البنرات الإعلانية.
- عرض المنتجات الجديدة والمميزة والأكثر مبيعًا.

### 10. صفحات المتجر

#### الصفحات الأساسية
- صفحة رئيسية تعرض المنتجات والأقسام والبنرات.
- صفحة من نحن.
- صفحة تواصل معنا ونموذج استفسارات.
- صفحة سياسة الشحن والتوصيل.
- صفحة الاستبدال والاسترجاع.
- صفحة سياسة الخصوصية.
- صفحة الشروط والأحكام.

### 11. لوحة الإدارة والموظفين

#### لوحة التحكم

- عرض ملخص المبيعات والطلبات والعملاء.
- متابعة الطلبات الجديدة.
- الوصول إلى أقسام الإدارة من مكان واحد.

#### الإدارة التشغيلية

- إدارة المنتجات والأقسام.
- إدارة المخزون والأسعار.
- إدارة الطلبات والفواتير.
- إدارة العملاء.
- إدارة المدفوعات والشحن.
- إدارة العروض والكوبونات.
- إدارة صفحات المتجر والبنرات.
- التحكم في إعدادات المتجر العامة.

#### الموظفون والصلاحيات

- إنشاء حسابات للموظفين.
- تحديد الصلاحيات حسب الدور الوظيفي.

#### إعدادات النظام

- إعدادات البريد الإلكتروني والإشعارات.
- إعدادات العملات والضرائب.
- إعدادات الشحن والدفع.



### 12. التقارير الأساسية

#### تقارير التشغيل
- عرض إجمالي المبيعات.
- مقارنة المبيعات خلال فترات زمنية.
- تقارير الطلبات المكتملة والملغاة.
- تقارير الإيرادات.
- المنتجات الأكثر مبيعًا.
- المنتجات النافدة أو منخفضة المخزون.
- عدد العملاء المسجلين والعملاء الجدد.
- تقارير المدفوعات والمرتجعات والمخزون.

### 13. الإشعارات والتواصل

#### الإشعارات
- إرسال رسالة تأكيد تسجيل الطلب.
- إشعار الإدارة بالطلبات الجديدة.
- إرسال إشعار عند تحديث حالة الطلب.
- إشعار إتمام الدفع.
- إشعار تجهيز أو شحن الطلب.
- إشعار الإلغاء أو الاسترداد حسب إعدادات النظام.

#### التواصل
- إرسال الإشعارات عبر البريد الإلكتروني.
- نموذج تواصل واستفسارات.
- عرض بيانات التواصل ووسائل الاتصال.
- رابط واتساب لخدمة العملاء.

### 14. الحماية والأمان والأداء

#### حماية المتجر

- تفعيل اتصال HTTPS باستخدام شهادة SSL.
- تشفير كلمات مرور المستخدمين.
- حماية جلسات تسجيل الدخول.
- تحديد صلاحيات المستخدمين.
- تقليل مخاطر الوصول غير المصرح به.
- تحديث المكونات البرمجية وسد الثغرات المعروفة.
- حماية البيانات الحساسة وفق إعدادات الاستضافة والنظام.

#### النسخ الاحتياطي

- إعداد نسخ احتياطية دورية.
- توفير آلية لاستعادة النسخ الاحتياطية.

#### الأداء وسهولة الاستخدام

- تحسين أحجام الصور والملفات.
- الاستفادة من التخزين المؤقت.
- تحسين استعلامات قاعدة البيانات.
- تحسين تحميل صفحات المتجر.
- توافق الواجهة مع الهواتف والأجهزة المختلفة.
- اختبار التصفح والشراء على المتصفحات الحديثة.
