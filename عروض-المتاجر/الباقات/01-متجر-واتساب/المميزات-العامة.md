# الباقة الأولى — متجر العرض والطلب عبر واتساب

واجهة احترافية لعرض المنتجات والأقسام، ينتهي فيها الطلب بإرسال تفاصيل المنتجات للمتجر عبر واتساب، دون نظام طلبات إلكتروني أو دفع داخل الموقع.

**مناسب لـ:** الأنشطة التي تستقبل طلباتها عبر واتساب وتحتاج كتالوجًا منظمًا باسمها.

## 1. واجهة المتجر

- تصميم احترافي متجاوب مع الهاتف والكمبيوتر.
- واجهة عربية واتجاه RTL وقوائم تنقل واضحة.
- صفحة رئيسية لعرض الأقسام والمنتجات المختارة.
- صفحات مستقلة للمنتجات مع الصور والأسعار والأوصاف.
- عرض الألوان والمقاسات والمواصفات للمنتجات.
- البحث عن المنتجات وتصفيتها حسب القسم والسعر.
- عرض المنتجات المرتبطة والمقترحة.

## 2. إدارة المنتجات

- لوحة إدارة لإضافة المنتجات وتعديلها وحذفها.
- إدارة الأقسام الرئيسية والفرعية والعلامات التجارية.
- رفع صور متعددة وإدارة الأسعار والعروض البسيطة.
- التحكم في ظهور المنتجات وتوفرها.

## 3. الطلب والتواصل

- زر طلب عبر واتساب للمنتج.
- إرسال اسم المنتج وخياره وكميته ورابطه ضمن رسالة واتساب جاهزة.
- تأكيد تفاصيل الطلب والدفع والتوصيل داخل محادثة واتساب بواسطة فريق المتجر.
- صفحة تواصل ونموذج استفسارات وروابط التواصل.

## 4. الإدارة والتشغيل

- إدارة البنرات والمنتجات الظاهرة في الصفحة الرئيسية.
- عرض معلومات المتجر وصفحة من نحن.
- اتصال HTTPS وتصميم سريع التحميل.

**الإضافات المستقبلية:** متاحة بصورة مستقلة خارج سعر الباقة، راجع ملف `../الإضافات-المستقلة.md`.
